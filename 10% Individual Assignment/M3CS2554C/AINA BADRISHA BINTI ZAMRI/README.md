# COMPREHENSIVE PERFORMANCE TESTING OF BLAZEDEMO WEB APPLICATION USING GRAFANA K6

Author: Aina Badrisha Binti Zamri

1. Overview

This project provides a detailed performance evaluation of the BlazeDemo airline booking website using the open-source testing tool k6 with Grafana Cloud for visualization. This project executed two tests, a scalability test (to measure behaviour while ramping users up and down) and a breakpoint test (to discover the point where latency or errors cross acceptable tresholds). All steps, test scripts, raw outputs, interpretation, and recommendations are included below.
